## 自动化实测抓出的关键 bug(修复过程)

1. **KeyE 按住无效**(致命):Input 的 KeyE 分支提前 return,keys 集合永远收不到按住状态——真实玩家将完全无法修复信标。浏览器自动化验收发现,重构为统一按键路径。
2. **看门狗自杀**:rAF 停滞检测与 timeout 兜底共用 lastFrameAt 计时,兜底帧自己刷新计时器导致 watchdog 每帧误判"rAF 已接管"退出。分离 rafLastAt/lastFrameAt 双时钟修复。
3. **彩蛋越界**:黑潮之心 (148,148) 半径 209m,超出 192m 玩家边界 clamp——玩家永远游不到。移至 (130,128)。
4. **vite dev 缓存**:HMR 后僵尸进程占端口,伺服旧模块——重启+换端口排除。
5. **视觉迭代**(截图评审驱动):初版下半屏过曝(bloom 0.85+蘑菇 emissive 1.8 叠加)→ 分层降参;角色黑暗中不可辨识 → 玩家随身 aura light;整体偏暗 → 环境光/曝光平衡;蘑菇稀疏 → 密度 200+径向渐变伞盖。
